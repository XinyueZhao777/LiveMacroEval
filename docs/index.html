Can LLMs Take the Pulse of the Economy?

A real-time evaluation of LLM nowcasts on sixteen U.S. headline macroeconomic indicators, scored against the equity market and prediction markets — and against the professional economists who do this for a living.

01Why a live benchmark

Nowcasting — estimating an indicator's value for the current reference period before its official release — is a core task in empirical macroeconomics, and central banks devote dedicated teams of expert economists to it. LLM agents look like natural candidates: they combine broad world knowledge with real-time web search, and they can be queried far more often than any institutional nowcast updates.

The contamination problem. GDP and CPI are among the most widely reported numbers on earth. Their historical values are almost certainly memorized during pretraining, so any evaluation on historical releases measures recall, not nowcasting. The only clean test is a strictly live one, where the target has not yet been released at prediction time.

LiveMacroEval runs that test. Every nowcast in the benchmark is produced inside a pre-release window that closes at the scheduled official release, so the target value cannot have entered the model's training corpus or its retrieved web content. The benchmark is contamination-free by construction — and it keeps running, which is why the numbers on this page move.

02The task

For each of 16 U.S. headline indicators, an LLM agent with web search produces an hourly nowcast over a window that opens in the final week of the reference month and closes at the official release — a span of weeks to months. The agent decides for itself when and what to search.

    Human experts + econometrics

    Bloomberg ECOS & auto-ARIMA

    The professional consensus, plus a standard time-series baseline.

    • Bloomberg ECOS — cross-sectional median of a panel of professional economists, covering all sixteen indicators. The canonical benchmark for real-time macro expectations, and well known to be extraordinarily hard to beat.
    • auto-ARIMA — univariate, refit at the start of each window.

    03How we score

    Plain MSE on the released level ignores that indicators differ wildly in economic importance, conflates prediction quality with each indicator's scale, and throws away the pre-release trajectory. We use two market-grounded metrics instead.

    Metric 1

    LiveMacro Score

    Does the nowcast explain how the equity market actually moved?

    Macro surprises — the gap between the released value and the prevailing consensus — causally move equity prices. We estimate each indicator's effect βi on E-mini S&P 500 futures over a tight [−5, +30] minute window around the release, on a long historical sample, frozen before any live outcome is scored. Each model's nowcast implies a surprise, hence an implied return.

    LiveMacro = (SScons − SSmodel) / (SScons + SSmodel)

    A bounded out-of-sample R². +1 = perfectly anticipates announcement-window returns. 0 = ties the Bloomberg consensus. −1 = arbitrarily worse. Because β weights each indicator by its measured market impact, sixteen accuracies collapse into one comparable number.

    Metric 2

    LiveBetting Score

    If you traded the nowcast, would you make money?

    Each Polymarket-style macro market is a set of mutually exclusive numeric buckets trading as binary contracts. At every hour strictly before the release we place a $1 bet on the bucket containing the agent's most recent nowcast, buying 1/p shares at the prevailing market price p.

    Because p is the crowd's implied probability, liquidity is priced into the return by construction: when the crowd is already right, winning pays little; when the crowd is wrong and the agent is right, it pays a lot. The metric rewards beating the crowd, and it is unit-free, so it aggregates directly across heterogeneous indicators. A single GPT-5 GDP window can contain over 1,400 hourly bets.

    05Results

    Over six months of live evaluation, the top LLM agent ties the professional consensus in aggregate — but the aggregate hides sharp heterogeneity across the economy.

    Where the skill is: by theme

    Decomposing the score by theme shows LLM agents exceed the consensus on Supply and Production and on Housing — plausibly because those themes rest on higher-frequency underlying components (mortgage applications, housing sentiment) that reward intra-window updating. They underperform on Demand and Inflation, consistent with the anchored-expectations regime that protects the consensus on headline inflation. Labor Market clusters near zero for every model, consistent with a signal-to-noise ceiling on the household survey.

    LiveBetting: trading against the Fed

    On real GDP, four LLM agents finish the window with positive cumulative returns and three beat the Atlanta Fed, with only the New York Fed ahead. On the unemployment rate the leading agent finishes above the Chicago Fed. On CPI, however, the Cleveland Fed and the Bloomberg consensus still lead every LLM agent — a real limitation on indicators where institutional models are tightly tuned to known economic structure.

    Case study: watching a belief update

    Hourly cadence makes it possible to trace, after the fact, how a single information event enters the agent's information set. GPT-5's March 2026 CPI nowcast sits around 2.7% through early April, then jumps to about 3% inside a tight intraday window on April 8 — a window containing both the EIA Petroleum Status Report (a large gasoline-inventory drawdown) and FOMC minutes flagging upside inflation risk. Both push the same direction, and the revision's magnitude is consistent with a back-of-the-envelope gasoline contribution under BLS expenditure weights.
